Cars Dealership – Full-stack Developer Capstone Project

Author: Cristina Parrales Toledo (@CristinaParralesT)

Project name

Best Cars Dealership – a web application for a national car retailer in the U.S.

Description

A responsive web application that lists the dealership branches across the U.S., lets users filter dealers by state, view dealer details and reviews, and allows registered users to post reviews about a dealership. Each review is analyzed with a sentiment analysis microservice.

Features
User registration, login and logout
List all dealers and filter dealers by state
Dealer details page with customer reviews
Post a review (logged-in users only)
Sentiment analysis of reviews (positive / neutral / negative)
Admin site to manage car makes and car models
Technologies
Frontend: React, HTML, CSS, Bootstrap
Backend: Django (Python), Node.js / Express
Databases: MongoDB, SQLite
Microservices: Flask sentiment analyzer on IBM Cloud Code Engine
DevOps: Docker, Kubernetes, GitHub Actions (CI/CD)
